# Technical sources

These primary or reference documents informed the original guidance. The skill paraphrases and summarizes; consult the version matching the target toolchain/platform.

- WG14, [N1570: C11 committee draft](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)
- GCC, [Warning Options](https://gcc.gnu.org/onlinedocs/gcc/Warning-Options.html)
- Clang, [AddressSanitizer](https://clang.llvm.org/docs/AddressSanitizer.html), [UndefinedBehaviorSanitizer](https://clang.llvm.org/docs/UndefinedBehaviorSanitizer.html), and [ThreadSanitizer](https://clang.llvm.org/docs/ThreadSanitizer.html)
- LLVM, [LibFuzzer](https://llvm.org/docs/LibFuzzer.html)
- The Open Group, [POSIX `read()`](https://pubs.opengroup.org/onlinepubs/9699919799.2018edition/functions/read.html)
- CMake, [CTest documentation](https://cmake.org/cmake/help/latest/manual/ctest.1.html)
- Meson, [Testing documentation](https://mesonbuild.com/Unit-tests.html)
- AFL++, [Documentation](https://aflplus.plus/docs/)
